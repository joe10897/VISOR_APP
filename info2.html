問題定義

🤔

環境感知挑戰

機車騎士需同時應對車輛、行人、號誌等多重動態目標，在複雜路況中難以全面兼顧，易生危險。

🏍️

駕駛行為風險

不當的駕駛行為，如車道偏移、彎道超速或過彎傾角過大，是造成機車自摔或碰撞事故的主要原因之一。

🌧️

極端條件限制

在夜間、雨天或起霧等惡劣天候下，人眼與攝影機的辨識能力皆會顯著下降，導致偵測精度不足。

目標與功能

⚠️

後方追撞警示

即時偵測後方車輛，並根據相對距離與位置判斷威脅，發出警示。

📐

過彎傾角警示

偵測機車過彎時的傾斜角度，當角度過大時提醒騎士，預防失控打滑。

👁️

即時物件偵測

辨識畫面中的行人、汽車、機車等用路人，提供全面的環境感知。

📊

行車資訊顯示

在畫面上即時顯示目前車速與傾角等關鍵數據，讓騎士一目了然。

多感測器融合

後方威脅判斷

融合以下三項條件，判斷後方物體是否構成威脅：

  • 距離估算: dist < 6.0 公尺
  • 垂直位置: cy > 60% 畫面高度
  • 模型信心度: conf > 0.4

當三者同時成立時，系統將觸發「後方威脅」警示。

# fusion.py
def is_rear_threat(self, obj, sensor_data):
    _, conf, bbox = obj
    cx, cy = utils.bbox_to_centroid(bbox)
    dist = self.estimate_distance(bbox)

    if dist < 6.0 and cy > (0.6 * self.h) and conf > 0.4:
        return True, dist
    return False, dist

傾角警示

根據感測器回報的傾斜角度，判斷車輛是否可能發生不穩或車道偏移：

  • 觸發條件:
    abs(tilt_deg) > 18.0 度

當偵測到機車傾角過大時，系統將觸發「傾角過大」警示，提醒騎士注意行車姿態。

模型設計

🧠

輕量化模型

選用 YOLOv8-nano 作為核心，此模型在維持高精度的同時，具備優異的推論速度，適合行動裝置。

# model_inference.py
from ultralytics import YOLO

class Detector:
    def __init__(self):
        # 載入 YOLOv8-nano 模型
        self.model = YOLO('yolov8n.pt')
⚙️

模型最佳化

未來可透過量化 (Quantization) 與剪枝 (Pruning) 等技術，進一步壓縮模型大小，降低運算需求。

🚀

即時推論效能

目標在主流智慧型手機上達到至少 15-20 FPS 的即時推論速度，確保警示的及時性。

開發流程

第一階段：資料與模型

收集與標註影像資料，完成初步的模型訓練與壓縮。

第二階段：核心功能開發

開發手機端 App 骨架，並整合感測器融合演算法。

第三階段：部署與整合

將訓練好的模型部署至手機，並與 App 完整對接。

第四階段：實地測試

分別在汽車與機車上進行實地測試，收集反饋。

第五階段：強健性與優化

針對雨天、夜間等惡劣環境進行測試，並優化效能。

視覺傳輸串接方案

使用 Raspberry Pi 5 搭配 ROS (Robot Operating System)、IMU 和 2MP USB 鏡頭組合

⚡️

性能與運算優勢 (Raspberry Pi 5)

  • AI 運算能力: CPU/GPU 性能顯著提升，能高效運行 YOLOv8 等複雜模型。
  • 多媒體處理: 可處理雙 2MP 鏡頭串流，並進行 H.264/H.265 硬體編碼。
  • 高速 I/O: 具備 USB 3.0 與 PCIe 2.0，確保數據穩定，並可擴充 AI 加速卡 (NPU)。
🤖

軟體架構優勢 (ROS)

  • 模組化設計: 將影像、IMU、警示等功能設計為獨立節點 (Node)，易於開發與維護。
  • 感測器融合: 成熟的工具包可輕鬆同步與融合視覺和 IMU 數據，提升 ADAS 穩定性。
  • 豐富生態系: 可利用 cv_bridge, tf, Rviz 等現成工具加速開發。
🧭

系統功能優勢 (IMU 與整合)

  • IMU 數據整合: 精準偵測加速度變化以觸發碰撞鎖檔，並提供姿態估計以提高追蹤準確性。
  • 靈活鏡頭選擇: 採用 UVC USB 鏡頭，具備即插即用特性，免去複雜的驅動開發。
🔌

供電方案

採用 12V DC to 5V/5A 降壓模組，為 Raspberry Pi 5 和周邊設備提供穩定電力。

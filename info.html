物件持續追蹤 (ID Persistence)

我們實作了基於中心點 (Centroid) 的歐幾里得距離匹配算法。即便 AI 在某一幀漏檢，追蹤器仍會根據快取位置預測物件路徑，並在設定的門檻內 (Max Disappeared) 保持物件 ID 的唯一性，這對於計算 TTC (碰撞預期時間) 的連續性至關重要。

  • 跨幀 ID 匹配：避免警報因偵測跳動而頻繁閃爍
  • 座標平滑化：過濾偵測框的細微震顫

智慧標框與視覺疊加

在 Pi 5 本地螢幕 (`--visual` 模式) 中，系統會將處理後的偵測框動態疊加於 RAW 影格。我們根據信心度動態調整邊框亮度，並在偵測到威脅時將綠色邊框瞬間轉化為高亮紅色，實現視覺上的直觀預警。

  • 動態 Label 繪製：顯示 Class Name 與 Confidence
  • 威脅分級渲染：根據距離自動變換框色與粗細

# vision/fusion.py
def classify_threat(self, det, class_name, history):
    dist = self.estimate_distance(det.bbox)
    ttc = self.calculate_ttc(dist, history)
    if dist < self.danger_dist or ttc < 1.5:
        return 'DANGEROUSLY_CLOSE', dist
    return 'STABLE', dist

效能優化黑科技

AI 跳幀 (Frame Skipping)

AI 每 2 幀處理一次，視覺維持 30 FPS，降低 50% CPU 佔用。

Asyncio 非阻塞

確保 AI 運算不阻塞 Socket 通訊線程。

未來展望與深度優化

AI 運算強化

計畫導入 OpenVINO 模型加速框架，並將 Centroid Tracker 升級為卡爾曼濾波器 (Kalman Filter)，提升物件遮擋時的追蹤穩定度。

智慧電源管理

連結 GPIO 與機車電門，實現自動騎乘/哨兵模式切換；並根據 CPU 溫度動態調整跳幀率，確保在夏日環境下的穩定性。

二進位協議

通訊 Payload 將從 JSON 遷移至 Protobuf 格式，並導入 WebRTC 技術，實現 App 端近乎 0 延遲的影像串流。

全感官互動

開發語音控制模組與個人化危險路圖系統，將騎士多次急煞的地點標記為「專屬警戒彎道」，實現主動式預防。

I. 研究背景與動機

機車道路安全危機與挑戰

二輪安全防護專題

在高密度混合車流中，機車騎士是最顯著的弱勢道路使用者 (VRUs)。頻繁的車流交織與視線盲區，直接放大了傷亡風險。

防護不對稱性

機車缺乏剛性車體結構保護，事故致死率高達小客車的 28 倍，碰撞即重傷。

行車環境死角與盲區

面對不當變換車道、惡意逼車或突發急煞，騎士僅有毫秒級的反應時間，傳統照後鏡死角極大。

I. 研究背景與動機

V.I.S.O.R. 系統提案

主動安全防護盾
在雷達區域移動游標，可模擬威脅車輛逼近。

提出次世代視覺智慧系統 V.I.S.O.R.

專為廣大機車族群打造的低成本、純視覺全方位主動安全防護盾──全面整合 YOLO26n 輕量模型 與 四階邊緣消抖引擎，將傳統被動安全帽進化為主動電子安全防護系統。

核心設計三大支柱
  • 雙向全時監控： 前鏡頭 120° + 後鏡頭 160° 廣角配置──提供近 280° 無盲區全景覆蓋。
  • 動態威脅分區： 即時判定威脅切入向量，依逼近方向自動切換前向防撞或後方盲區預警模式。
  • 直覺 HUD 燈號與蜂鳴預警： 將複雜道路數據淬鍊為安全帽 HUD 極簡動態閃爍燈號與立體蜂鳴聲響──提供即時示警的同時絕不增加認知負荷，保留騎士專注路況的寶貴專注力。

為何選用次世代 YOLO26n？

  • 極致輕量化：僅 2.37M 參數（比 v8n 減少 26%），模型僅 5.4MB
  • 超低計算量：僅 5.3 GFLOPs，專為樹莓派 Pi 5 純 CPU 量身打造
  • 高精度收斂：RTX 5070 訓練 95 輪，汽車精確率達 72.4%、機車 mAP 達 61.1%

全鏈路 4:3 矩形原生架構（消滅黑邊）

傳統 YOLO 預設 640×640 填補了 25% 無效黑邊 (Letterbox)。本研究實現相機輸入 640×480 ➔ 訓練 640×480 (`rect=True`) ➔ Pi 5 推論 384×288，像素運算量直降 64.0%，幀率躍升至 30+ FPS。

堅持「純 CPU 本機邊緣運算」之必要性

機車行車安全需毫秒級即時反應（TTC < 1.0s），雲端推論傳輸延遲高達 50~200ms，在山區或隧道斷網更直接失效。V.I.S.O.R. 捨棄昂貴外接 GPU，直接以百元有找之 Pi 5 純 CPU 達成 26~41ms 全鏈路推論，系統功耗 <15W，支援 12V 機車電瓶直驅。

運算與顯示硬體級解耦 (Decoupling)

單板電腦若同時進行雙路 4:3 影像擷取、AI 卷積與螢幕 GUI 渲染，將因 GPU/CPU 資源搶奪引發嚴重掉幀與畫面撕裂。本架構將 Pi 5 置於車身專職高負載運算，Pi Zero 2W 置於安全帽專職 HUD 顯示，徹底消除資源競爭。

微秒級自定義 UDP 廣播協定

通訊層捨棄 HTTP/TCP 握手重試開銷，採用輕量自定義二進位 UDP 封包（小於 128 bytes），實測傳輸時間僅 0.8~1.2 ms，單幀偶發丟失絕不造成隊列阻塞，保障極致流暢之 HMI 警示體驗。

1. BDD100K 駕駛情境精選子集 8,461 張

涵蓋逆光、夜間低光、暴雨濃霧；特選近距大型車輛（面積 >12%），強化模型對大型車輛逼近之泛化感知。

專用機車廣角後視鏡視角與車側死角，針對後方高速逼近、貼車超車等盲區情境進行深度標註。

4. 空曠道路純負樣本 (Background Negatives) 468 張

無任何車輛之空曠道路、柏油反光與隧道牆面，有效壓制無關紋理的幽靈誤檢 (Ghost Boxes)。

五大類別： 汽車 83,115 (44.9%) 行人 49,642 (26.8%) 機車 14,756 (8.0%) 大貨卡車 6,841 (3.7%) 單車 1,600 (0.9%)

攻克「小目標檢測 (Small Object)」難題

騎士視角挑戰： 距車身 15~30 公尺的遠端機車與行人僅佔影像中 <24×24 px。傳統 YOLO 的 640×640 正方形 Letterbox 黑邊填充佔據 25%，導致遠距微小目標在多層下採樣後特徵消失。
解法 1：全管線 4:3 原生幾何 (384×288)

捨棄黑邊填充，將有限畫素 100% 聚焦於道路水平視野，小目標有效特徵像素密度提升 33.3%，計算量同時降低 64.0%。

解法 2：P3/8 淺層高解析特徵金字塔保真

YOLO26n 跨層架構保留 48×36 的 P3 淺層特徵圖，直接串接微小目標檢測頭，精確捕捉遠距機車輪廓與邊緣梯度。

解法 3：多尺度 Mosaic 隨機拼接數據增強

隨機縮放拼接 4 張路況影像，在單幀中創造大量微小尺度目標（<32×32 px），強制模型深度學習微小尺度細節，遠端目標召回率顯著提升。

關鍵標註瑕疵修復： 人工校準盲區資料集中 845 處 將大型重機與速克達誤標為汽車之標註缺陷，消除混淆特徵，使機車 mAP50 從 30.2% 直衝 61.1% (+102.3%)！
III. 研究方法與創新貢獻

四階邊緣消抖防護引擎與感知架構

車載級穩定性

四階邊緣消抖防護引擎 (Sentinel Engine)

單目測距微分痛點： 邊框寬度因光影產生 ±2 px 抖動，時間差分後使接近速度 $v_{\text{rel}} = \frac{\Delta d}{\Delta t}$ 暴衝至 45 m/s (162 km/h)，導致均速跟車時警報顏色在綠 ↔ 黃 ↔ 紅之間瘋狂跳色。
$$d^{(t)} = \max\left(0, \frac{W_{\text{real}} \times f}{w_{\text{bbox}}^{(t)}} - 3\right), \quad TTC = \frac{d^{(t)}}{\max(v_{\text{rel}}^{(t)}, 0.1)}$$
① 行人分流 (Offload)：路側行人跳過追蹤運算，釋放 Pi 5 達 35% CPU
② 雙指數平滑 (EMA)：$D_t = 0.35 D_{\text{raw}} + 0.65 D_{t-1}$，徹底平滑距離曲線
③ 速率門檻過濾：$v_{\text{rel}} > 0.6\text{ m/s}$ 才判定逼近，均速跟車強制關閉紅燈
④ 鄰道隔離與施密特遲滯：鄰道最高限黃燈；降級具備 1.5m 緩衝 + 0.25s 冷卻
實測成效： 成功消除 244 次無效雜訊閃爍 (穩定度提升 31.5%)，警示達到車載級 HMI 標準！

幾何車道感知與三級預警決策

$$x = \frac{c_0}{(y-c_1)^2} + \frac{c_2}{(y-c_1)} + c_3 + c_4 y - c_5$$
